# How Commons was built

Commons was written on 22 November 2026 by a coordinating agent and several app agents. Each app was then reviewed
by an agent that had not written it. These are the briefs they worked from, kept as a record:

- `BRIEF.md`: what the suite changes from the panes-lab brief the apps started under.
- `BRIEF-PHASE2.md`: how every app was restyled to the design sheet (`../design/DESIGN.md`).
- `BRIEF-REVIEW.md`: the reviewers' brief (each `REVIEW.md`, and the two-person tests).
- `verify-baseline.log`: the first test run, before any restyling.

Paths in them (`~/ideas/…`) are from the machine they were written on.
