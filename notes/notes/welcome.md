# Notes in a pod

This is a plain Markdown file. The notes pane shows it as a page: headings, lists, tables, code, links.

## Links between notes

Write the name of another note in double square brackets and it becomes a link:

- [[linking]] explains the three ways to link.
- [[2026-11-18-first-entry|A dated entry]] shows a label, and how dates are handled.
- [[not-written-yet]] has no file, so it is shown greyed instead of leading to an error.

Ordinary Markdown links work too: [the linking note](linking.md).

## What else it shows

| Markdown | Shown as |
|---|---|
| `# Heading` | a heading |
| `- [ ] task` | a checkbox |
| `**bold**` | **bold** |

- [x] Write a note
- [ ] Link it to another
