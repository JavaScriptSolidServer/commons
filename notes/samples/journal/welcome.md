# Alice's notebook

Plain Markdown files in a folder on Alice's pod. The notes pane shows each one as a page.

## Links between notes

- [[linking]] explains the ways to link one note to another.
- [[seed-swap|The seed swap]] is a dated note, found without its date.
- [[not-written-yet]] has no file, so it is shown greyed.

An ordinary Markdown link works too: [the shopping list](shopping-list.md).

## What else it shows

| Markdown | Shown as |
|---|---|
| `# Heading` | a heading |
| `- [ ] task` | a checkbox |
| `**bold**` | **bold** |

> Notes are files you own: any app can read them.
