Notes pane

Markdown notes in a Solid pod, read as pages in the SolidOS data browser, with links between notes. The pane is one module, loaded by link.

Open a note

The data browser asks before it adds a pane from a site it has not seen. Allow it, and the note opens as a page. Write [[another-note]] in a note and it becomes a link to it.

The pane: https://solid-panes.github.io/notes/notes-pane.js

Source and details: github.com/solid-panes/notes
